# Veil Clubs

Confidential PoolTogether-style social prize pools.

## Workspace

- `frontend/`: React/Vite landing page and app workspace. The existing visual style and Three.js globe live here.
- `contracts/`: Hardhat Solidity contracts for ERC-7984 confidential deposits and Veil Clubs pool logic.
- `backend/`: reserved for optional keeper/indexer/faucet services.
